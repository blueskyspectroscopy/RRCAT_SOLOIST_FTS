# RRCAT_SOLOIST_FTS

Based on the last apparent version sent to RRCAT on 2019-09-19. 

This was last modified by Sudhakar and Trevor to implement the SI mode, rather that the originally recommended slow-scan SI mode. 

This was based on IDL 8.7 and old versions of the MC1808X, DT9800 and serial DLMs. IDL 8.7 is compatible with the new license server, if the l3harris nextgen license patch application from IDL 8.8 is used.

The 19 September 2019 version modified the package delivered on 12 Sept 2019:
- Change motor for FTS selection mirror from Motor A to Motor Z (M5 to M4).

- rrcat_soloist_fts.pro
- rrcat_stepper_parse_string.pro
