IDLffJPEG2000::Cleanup

The IDLffJPEG2000::Cleanup procedure method performs all cleanup on the object.

Note: Calling OBJ_DESTROY will also close any files that have been opened for reading or writing.

Syntax

Obj->Cleanup

or

Obj -> [IDLffJPEG2000::]Cleanup

or

OBJ_DESTROY, Obj

Arguments

None

Keywords

None
