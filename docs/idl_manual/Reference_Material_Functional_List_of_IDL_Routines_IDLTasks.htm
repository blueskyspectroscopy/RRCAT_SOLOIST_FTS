IDL Tasks

Tasks

IDLQueryAllTasksTask: Returns a hash where each key is the task name and each task name key contains a hash of the task's properties.

IDLQueryTaskCatalogTask: Returns a list of the tasks available in IDL.

IDLQueryTaskTask: Returns a hash that describes the properties of an IDL task.
