Tooltips

You can specify a “tooltip,” which is a short text string that will appear when the mouse pointer hovers over a button widget. To do this, specify the string as the value of the TOOLTIP keyword to WIDGET_BUTTON.

Tooltips cannot be created for menu sub-items. The topmost button of a pulldown menu can, however, have a tooltip.
